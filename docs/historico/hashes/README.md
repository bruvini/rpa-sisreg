# Checksums históricos

Esta pasta conserva os arquivos de hash publicados nas versões anteriores. Eles não são usados na execução ou compilação do aplicativo.

Para conferir o executável atual, compare o arquivo baixado com o `SHA256.txt` do mesmo artefato **RPA_SISREG_Windows** no GitHub Actions. Um hash antigo desta pasta não valida um executável novo.
